Frame Injection Test Bed

Test iframes with different src types, both static and dynamically injected.

Static Iframes

about:blank — src="about:blank" + document.write on load

srcdoc — srcdoc attribute (inline HTML)

blob: URL — src="blob:..." (URL.createObjectURL, set on page load)

cross-origin — src="https://example.com" (IANA example domain, no X-Frame-Options)

data: URL — src="data:text/html,..." (blocked in Chrome 60+ for security)
